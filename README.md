# next-platform-starter

This repository contains early work on the EchoVibe music app (see the `mus` file for the React component).

## Completed Android Version

The robust, installable Android app is available at [echovibe-android](https://github.com/Whatpopping/echovibe-android).

It is built with React + Vite + Tailwind + Capacitor, and APKs are generated via GitHub Actions.
